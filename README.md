## Featured Project

### 🚗 Vallena — Carpooling Platform
> Final Degree Project &nbsp;·&nbsp; ASP.NET Core · PostgreSQL · Redis · AWS · Expo (React Native) · React.js · SignalR · OpenTelemetry

A full-featured ride-sharing platform with a mobile app for trip coordination and a web admin panel for moderation, validation workflows, and monitoring dashboards.

**Key features:**
- Ride creation and joining, vehicle management, ratings, and in-app real-time chat
- CO2 footprint reduction and fuel cost savings estimates per shared trip
- Geolocation via OpenStreetMap, JWT authentication, and payment processing
- Modular monolith backend with Redis caching, AWS S3 storage, and structured observability via OpenTelemetry

Completed and deployed on AWS. Not published to app stores by team decision.

*Private repository.*

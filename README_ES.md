## Proyecto destacado

### 🚗 Vallena — Plataforma de carpooling
> Proyecto Final de Carrera &nbsp;·&nbsp; ASP.NET Core · PostgreSQL · Redis · AWS · Expo (React Native) · React.js · SignalR · OpenTelemetry

Plataforma de viajes compartidos con una app mobile para coordinación de viajes y un panel web de administración para moderación, validaciones y monitoreo.

**Funcionalidades principales:**
- Creación y unión a viajes, gestión de vehículos, calificaciones y chat en tiempo real
- Estimación de reducción de huella de CO2 y ahorro en costos de combustible por viaje compartido
- Geolocalización con OpenStreetMap, autenticación JWT y procesamiento de pagos
- Backend monolito modular con caché Redis, almacenamiento en AWS S3 y observabilidad estructurada con OpenTelemetry

Completado y desplegado en AWS. No publicado en tiendas de aplicaciones por decisión del equipo.
